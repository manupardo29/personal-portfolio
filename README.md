# Manuel Pardo - Personal Portfolio

A clean, responsive, one-page portfolio website for IT Support, Customer Support, Technical Support, Help Desk, Systems, QA trainee/junior, and Junior Developer applications.

The site is built with plain HTML, CSS, and JavaScript so it can be deployed easily with GitHub Pages.

## Files

- `index.html` - Main portfolio page and content.
- `styles.css` - Responsive layout and visual design.
- `script.js` - Mobile navigation and active section highlighting.
- `assets/` - Place the downloadable CV PDF and future static assets here.

## Preview locally

Open `index.html` directly in your browser, or run a small local server from the repository root:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository on GitHub.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch you want to publish, usually `main`.
6. Select the root folder `/`.
7. Save the settings and wait for GitHub Pages to publish the site.
